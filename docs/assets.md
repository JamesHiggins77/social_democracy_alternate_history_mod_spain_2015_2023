# Image assets

Every image used by the Spanish game, with its source and licence. Images must be public domain or openly licensed; record each one here before use (Chapter I doc, "Visual assets and image sourcing"). CC BY and CC BY-SA require attribution; CC BY-SA also requires that adapted versions (including resized copies) keep the same licence.

Download or refresh the files with `python3 tools/fetch_images.py`. It fetches Wikimedia's standard thumbnail sizes into `out/html/img/spain/` and checks each file's licence against this list.
